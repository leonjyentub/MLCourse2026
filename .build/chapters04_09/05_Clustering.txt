===== SLIDE 15 =====
Expectation-Maximization 
(EM) algorithm 
Maximization
 (EM)
演算法，它與
K-Means 
演算法有許多相似之處
決定群集的數量。
初始化每個群集的平均值、變異數和權重參數。
使用期望最大化演算法
(Expectation Maximization algorithm )
執行以下操作：
期望步驟（
expectation
 
ste
p
,
 
E
步）：計算每個數據點屬於每個數據點的機率，將實例分到群聚，然後使用當前參數估計值
(current estimate for the parameters)
計算似然函數
(likelihood function)
。
最大化步驟（
 maximization step 
M
步）：更新先前每個群聚的平均值、變異數和權重參數，以最大化
E
步中發現的期望似然值。
重複這些步驟直到模型收斂。
===== SLIDE 16 =====
Expectation-Maximization 
(EM) algorithm 
在分群的背景下，你可以將
EM 
當成
K-Means 
的普遍版，它不但可以找出群聚中心 
，
也可以找到它們的大小、形狀與方向
，
以及它們的相對權重。
但與
K-Means 
不同的是，
EM 
使用
軟群聚分配
，不是硬分配。
在期望步驟，演算法會幫各個實例估計它屬於各個群聚的機率（根據當前的群聚參數）。
接下來，在最大化步驟，演算法會用資料組的所有實例來更新各個群聚，各個實例的權重是它屬於該群聚的估計機率，這些機率稱為實例的群聚責任。

階層式分群不需要預先定義群集的數量  𝐾
分群結果是一種基於樹狀結構的表示法，稱為「樹狀圖」
建立樹狀圖主要有兩種方法：
凝聚式分群（即自下而上）
假設我們有 𝑛 個樣本，每個樣本具有 𝑝 個特徵。在進行分群之前，需要決定一個「不相似度」的衡量方法 
-
 假設先使用歐幾里得距離。
最初，每個樣本會形成一個單獨的群集。在每次迭代中，會合併那些彼此之間不相似度最低（即最相似）的群集。
使用「不相似度」這個詞是因為不相似度將表示

不相似度計算
計算兩個樣本之間的距離（例如歐幾里得距離），但如何計算兩個群集之間或一個群集與一個樣本之間的距離呢？透過「連結」來解決
-
連結提供了一種將多個值整合為單一數值的方法。主要有以下四種類型的連結方式：
完全連結（
Complete Linkage
）：
計算群集中所有觀測點之間的成對距離，並取其中的最大值。
單一連結（
Single Linkage
）：
從所有成對距離中取最小的距離。
平均連結（
Average Linkage
）：
記錄所有成對距離的平均值。
沃德連結（
Ward Linkage
）：
計算基於群內變異的距離，以最小化群內的總平方差。

===== SLIDE 24 =====
DBSCAN
Density-Based Spatial Clustering of Applications with Noise
For each instance, the algorithm counts how many instances are located within a small distance 
ε (
epsilon) 
from it. This region is called the instance’s 
ε-
neighborhood.
If an instance has at least 
min_samples
 
instances in its 
ε-
neighborhood (including itself), then it is considered a 
core instance
. In other words, core instances are those that are located in dense regions.
All instances in the neighborhood of a core instance belong to the same cluster. This neighborhood may include other core instances; therefore, a long sequence of neighboring core instances forms a single cluster.
Any instance that is not a core instance and does not have one in its neighborhood is considered an anomaly.
